# 지원 완료 API

**현재 지원 완료 API: 0개.** 이 페이지에는 실제로 구현하고 동작 근거를 확보한 API만 추가합니다.

## 등록 기준

[API 명세 필수 항목](./README.md)에 따라 버전, 함수·태그·CSS 문법, 타입, 오류, 플랫폼 차이, 예제와 실제 동작 근거를 작성합니다. [구현 상태 대장](../STATUS.md)의 해당 항목에도 명세 링크를 연결해야 완료로 표시합니다.

제안 계약은 [명세 인덱스](../README.md)에서 볼 수 있습니다. 제안 항목은 지원 API 목록에 포함하지 않습니다.

## API 분류

| 분류 | 앞으로 게시할 명세 | 현재 상태 |
| --- | --- | --- |
| HTML 요소·이벤트 | 태그, 속성, 기본 동작, 입력·접근성 의미 | 제안 |
| CSS | 선택자, 속성, 값, 단위, 웹과 다른 점 | 제안 |
| JavaScript 호스트 API | 타이머, 네트워크, 저장소 등 V8 밖에서 제공하는 기능 | 제안 |
| 프레임워크 어댑터 | React·Vue·Svelte 연결과 지원 버전 | 제안 |
| CLI·개발 도구 | 명령, 인자, 출력, 종료 코드, Inspector·MCP | 제안 |
| 라우팅·OTA | 화면 이동, 번들 호환성, 릴리스 매니페스트와 업데이트 동작 | 제안 |

각 API 페이지는 React Native의 컴포넌트·API 레퍼런스와 Lynx의 요소·CSS 레퍼런스처럼 **문법/시그니처 → 예제 → 플랫폼 차이 → 지원 버전 → 동작 근거**를 제공하는 것을 목표로 합니다. 아직 개별 API를 `지원`으로 표시하지 않습니다.
