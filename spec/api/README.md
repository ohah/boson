# 스피논 API 명세 목록

**현재 지원 완료 API:** 없음. 이 폴더에는 구현과 적합성 근거가 확인된 공개 API의 버전별 명세를 둔다. [구현 상태 대장](../STATUS.md)의 기능 항목은 이곳 또는 내부 인터페이스 명세와 실제 동작 근거를 연결하기 전에는 완료로 표시하지 않는다.

## API 문서 필수 항목

각 API 문서는 다음 내용을 빠짐없이 기록한다.

1. 이름·패키지·명세 버전·첫 지원 버전과 지원 플랫폼/프레임워크/번들러.
2. 함수 시그니처 또는 태그·속성·이벤트·CSS 문법, 입력값·출력값·기본값과 타입.
3. 호출 순서, 비동기·취소·오류·수명·스레드 경계와 접근성 동작.
4. 웹·Android·iOS에서 다른 동작과 미지원 범위 및 실패 시 진단.
5. 복사해 실행할 수 있는 최소 예제와 결과.
6. 해당 구현의 소스 위치, 적합성 시나리오, 브라우저/실기기 증거와 알려진 제한.
7. 호환성을 깨는 변경일 때 이전 버전과 마이그레이션 방법.

기능 구현 PR은 API 문서를 새로 만들거나 기존 문서를 같은 PR에서 수정한다. `제안` 단계의 문서는 API 형태를 논의하는 데 사용할 수 있지만 `지원` 배지를 붙이지 않는다. 내부 전용 인터페이스도 호출자·입출력·오류·소유권을 명세하고 [구현 상태 대장](../STATUS.md)에 연결한다.
