# 스피논 API 문서

스피논의 **공식 구현 상태와 공개 API 계약**을 확인하는 곳입니다. 저장소의 Markdown이 원본이며 이 사이트는 같은 파일에서 생성됩니다.

> 현재 `0.1.0-draft` 설계·PoC 단계입니다. 제품 지원 완료 항목과 API는 아직 없습니다. 제안 명세는 구현 완료를 뜻하지 않습니다.

## 먼저 볼 문서

- [구현 상태 대장](./STATUS.md): 로드맵 75개 항목의 완료 조건과 현재 상태.
- [지원 완료 API 목록](./api/index.md): 구현 시 필수로 제공할 API 명세 항목.
- [명세 인덱스](./README.md): UI·HTML/CSS/JS·빌드·개발 도구·라우팅의 제안 계약.

## 문서를 읽는 순서

1. 구현 상태 대장에서 항목이 완료됐는지 확인합니다.
2. 완료된 기능의 API 명세에서 지원 버전·플랫폼·입출력·오류·예제를 확인합니다.
3. 해당 항목에 연결된 실제 기기/브라우저 동작 근거와 제한을 확인합니다.

기능 구현 PR에는 해당 항목의 상태 변경과 API 명세를 함께 넣습니다. PoC와 설계 초안은 제품 지원으로 표시하지 않습니다.
