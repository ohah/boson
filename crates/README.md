# Rust 워크스페이스

루트 [`Cargo.toml`](../Cargo.toml)이 제품 Rust 크레이트의 워크스페이스입니다. 실제 코드와 테스트가 준비된 크레이트만 구성원으로 추가합니다. 인터페이스와 소유권 계약이 정해지기 전에는 빈 크레이트를 만들거나 스파이크 코드를 제품 모듈처럼 연결하지 않습니다. 첫 크레이트가 들어올 때 workspace 테스트 명령도 함께 설정합니다.

예정 구조와 작업 순서는 [모노레포 구현 계획](../docs/plans/implementation.md)을 참고합니다. 공식 구현 상태와 완료 판정은 [상태 대장](../spec/STATUS.md)만 기준으로 삼습니다.
