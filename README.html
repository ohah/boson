    #스피논 명세 인덱스

    명세 버전: 0.1.0-draft · 상태: 제안 · 대상: 웹, Android, iOS

    이 폴더는 스피논의 공개 동작과 구현 사이의 계약을 정의한다. 현재 파일은 구현 완료 선언이 아니다. 스피논의 공개 요소는 HTML 이름을 사용하며 호스트 계약은 프레임워크에 독립적이다.

    공식 구현 상태: 78개 로드맵 항목과 JS API 세부 체크리스트 · 지원 완료 API: API 명세 목록. 구현 항목은 API/인터페이스 명세와 동작 근거를 함께 등록해야 완료로 표시한다.

    초기 빌드 연결에만 쓰는 내부 인터페이스는 내부 명세 목록에 둔다. 내부 부트스트랩의 존재는 앱 작성자용 API 지원을 뜻하지 않는다.

    #읽는 법

    • 제안 계약: 이 버전의 목표 동작이다. 구현이 갖춰지기 전에는 지원 기능으로 표시하지 않는다.
    • 미정: 화면·이벤트·오류·성능의 관찰 가능한 동작을 아직 결정하지 못했다. 미정 항목은 지원이라고 표시할 수 없다.
    • 확인된 구현: 기기·빌드·원본 결과가 연결된 경우에만 별도 증거 링크로 표시한다. 이 초안에는 적합성을 획득한 항목이 없다.

    이 spec/은 동작 계약을 정한다. 공개 HTML 대응표는 기능을 찾기 위한 안내이며 규범 명세의 상태를 대신하지 않는다.

    #변경 규칙

    1. 관찰 가능한 동작 변경에는 해당 명세의 범위·예제·실패 동작·웹/Android/iOS 차이를 함께 수정한다.
    2. 지원 항목에는 세 플랫폼의 검증 시나리오와 증거를 연결한다. 웹과 모바일 동작이 다르면 차이를 명시한다.
    3. 호환되지 않는 변경은 명세 버전, 번들 형식 버전, 호스트 API 버전 중 영향 받는 경계를 구분한다.
    4. 구현 세부 사항인 GPU API·스레드 개수·V8 핸들 형식은 공개 계약이 필요한 경우에만 이곳에 넣는다.
    5. 완료 상태의 변경은 구현 상태 대장의 같은 항목과 API/인터페이스 명세를 함께 갱신한다. 제안 문서나 PoC만으로 완료 체크를 하지 않는다.
